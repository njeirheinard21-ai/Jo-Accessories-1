# Administrator Manual

## Overview
The Jo Accessories Admin Dashboard provides comprehensive tools for managing the business.

## Sections
- **Dashboard**: Real-time sales and order overview.
- **Orders**: View, process, and refund orders.
- **Products**: Manage catalog, pricing, and stock.
- **Customers**: View customer profiles and purchase history.
- **Marketing**: Create discounts and campaigns.
- **CMS**: Manage pages and content.
- **Staff**: Manage team roles (Super Admin only).
